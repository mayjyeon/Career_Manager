Firebase 설정이 필요합니다

  1. Firebase Console에서 프로젝트를 만들고 웹 앱을 등록합니다.
  2. Authentication → Sign-in method 에서 Google 로그인을 사용 설정합니다.
  3. Firestore Database 를 만들고 firestore.rules 의 보안 규칙을 적용합니다.
  4. assets/js/firebase-config.example.js 를 firebase-config.js 로 복사해 값을 채웁니다.

자세한 순서는 저장소의 README.md 를 참고하세요.
